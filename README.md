# ICT Assignment 1 — E-Commerce Application

## Project Overview
A console-based e-commerce application developed in Java using object-oriented programming principles.

## Main Features
- User authentication
- Product management
- Customer orders
- Order total calculation
- Stock validation and updates
- Separate customer and employee functionality

## Project Structure
- `main` — application entry point
- `model` — users, products, and orders
- `service` — store operations

## Technologies
- Java
- Object-Oriented Programming (OOP)
- ArrayList collections
